## Estructura del proyecto

- index.html: archivo principal (contenido y estilos)
- img/: imágenes del sitio (foto de perfil y fondos)
- README.md: documentación del proyecto
- AGENTS.md: notas para flujo de trabajo con agentes
- opencode.json: configuración del workspace

## Cómo visualizarlo localmente

1. Abre index.html en cualquier navegador.
2. No necesitas instalar dependencias.
3. No hay build, ni servidor obligatorio para verlo.

## Personalización rápida

1. Cambia textos de perfil en el header y en la sección Sobre Mí.
2. Sustituye imágenes en img/ (por ejemplo, foto de perfil o fondo).
3. Ajusta colores y estilos en el bloque CSS dentro de index.html.
4. Actualiza enlaces de contacto (email, LinkedIn, GitHub).
